BI-1Y contour coordinate self-test

Developer-only physical calibration check. Not annotation, not production, not wired into the consumer app. Uses the SAME annotation-workbench.cjs and the SAME #imgStack > #img CSS transform structure as tools/annotation-workbench/index.html, so a click routed through this page exercises the real event path, not a reimplementation. Nothing here reads or writes autosave, uploads anything, or touches annotation data. Safe to delete this one file at any time.

Instructions

  1. Click the 5 numbered crosshair targets on the image, in any order, at the default display (rotation 0°, mirror off, zoom 1×). Each click is scored PASS/FAIL immediately.
  2. Click Reset this round, change rotation and/or mirror and/or zoom, and repeat.
  3. Also try resizing the browser window (reflow) between rounds.
  4. All rounds should show PASS for all 5 targets, with pixel error near 0.
Tolerance: canonical image pixels (out of an 800×500 image).
